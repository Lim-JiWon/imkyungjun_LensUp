# LensUp

> 공공 민원 데이터를 수집하고 분석하여 주요 이슈와 변화 흐름을 보여주는 AI 기반 민원 분석 서비스

🔗 **배포 사이트:** https://imkyungjun-lens-up.vercel.app/

---

## 프로젝트 소개

LensUp은 공공 민원 데이터를 활용하여 반복적으로 나타나는 키워드와 민원 이슈를 분석하고,  
사용자가 결과를 쉽게 확인할 수 있도록 웹 화면으로 제공하는 팀 프로젝트입니다.

민원 데이터를 직접 수집·정리한 뒤 AI 분석을 거쳐 서버에 전달하고,  
프론트엔드에서는 대시보드와 검색 화면을 통해 분석 결과를 보여줍니다.

---

## 주요 기능

- 공공 민원 데이터 수집
- 수집 데이터 정제 및 형식 통일
- 민원 관련 키워드 탐색
- AI를 활용한 민원 내용 요약 및 분석
- 분석 결과를 JSON 형식으로 변환하여 서버에 전달
- 민원 이슈 조회 및 검색
- 대시보드와 지도 기반 데이터 시각화

- Backend 서버에 전달할 JSON Payload 생성
- 데이터 전송 및 연동 테스트

## 데이터 처리 과정

```text
공공 민원 데이터 수집
        ↓
데이터 정제 및 형식 통일
        ↓
키워드 탐색 및 AI 분석
        ↓
JSON Payload 생성
        ↓
FastAPI 서버 전달 및 DB 저장
        ↓
React 화면에서 결과 시각화
```

## 팀 프로젝트를 통해 경험한 점

- 외부 공공데이터 API를 실제 프로젝트에 연동하는 과정
- 서로 다른 데이터 형식을 서비스에서 사용할 수 있도록 정리하는 과정
- 데이터 파이프라인과 백엔드 서버 간의 데이터 전달 방식
- 역할을 나누어 하나의 웹서비스로 통합하는 협업 과정
