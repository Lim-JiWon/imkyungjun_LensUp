# LensUp

> 공공 민원 데이터를 수집·정제하고 AI로 분석하여 지역별 주요 이슈와 변화 흐름을 제공하는 웹서비스

🔗 **배포 사이트:** https://imkyungjun-lens-up.vercel.app/

---

## 프로젝트 소개

LensUp은 공공 민원 데이터를 활용해 반복적으로 나타나는 키워드와 지역별 이슈를 분석하고,
그 결과를 대시보드·지도·검색 화면으로 제공하는 캡스톤디자인 팀 프로젝트입니다.

공공데이터 API에서 민원 데이터를 수집한 뒤 공통 형식으로 정리하고,
AI 분석 결과를 JSON Payload로 구성해 FastAPI 서버와 PostgreSQL에 전달합니다.

---

## 핵심 개선 결과

| 개선 항목 | 개선 전 | 개선 후 | 결과 |
|---|---:|---:|---|
| 지도 GeoJSON 파일 | 약 78.5MB | 약 0.54MB | 파일 크기 약 **99.3% 감소** |
| 외부 API 대량 요청 | `502 Bad Gateway`, `504 Gateway Timeout` 반복 | 요청량 축소 및 분할 수집 | 필요한 민원 데이터 수집 완료 |

### GeoJSON 경량화

지도 화면에서 사용하는 GeoJSON 파일이 커 로딩이 지연되는 문제가 있었습니다.
서비스에 불필요한 속성을 제거하고 경계 좌표를 단순화해 지역 경계는 유지하면서
파일 크기를 약 **78.5MB에서 0.54MB로 줄였습니다.**

### 외부 API 오류 대응

많은 데이터를 한 번에 요청할 때 외부 Open API에서 `502`, `504` 오류가 반복됐습니다.
수집 코드·요청값·JSON 생성 과정을 점검하고 API 운영기관에 오류 상황을 문의했습니다.
외부 서버 문제임을 확인한 뒤 한 번에 요청하는 데이터 수를 줄이고 여러 차례 나누어 수집하도록 수정해
필요한 데이터를 확보했습니다.

## 주요 기능

- 공공 민원 데이터 수집
- 기관별 API 응답 데이터 정제 및 공통 형식 변환
- 민원 관련 키워드 탐색
- AI를 활용한 민원 내용 요약 및 이슈 분석
- 분석 결과를 JSON Payload로 구성해 서버에 전달
- 지역별 민원 이슈 조회 및 검색
- 대시보드와 지도 기반 데이터 시각화
